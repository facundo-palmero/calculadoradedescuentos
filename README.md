# 🧮 Calculadora de Descuentos por Categoría

Este es un programa sencillo escrito en *Python* que permite calcular el precio final de un producto aplicando un descuento basado en el rango del cliente (Oro, Plata o Bronce).

## 🚀 Funcionalidades

El script solicita al usuario el precio original y su categoría, aplicando automáticamente las siguientes reglas de negocio:

| Categoría | Descuento | Multiplicador |
| :--- | :--- | :--- |
| *Oro* | 30% | 0.30 |
| *Plata* | 20% | 0.20 |
| *Bronce* | 10% | 0.10 |
| *Otros* | 0% | 0.00 |

1. Asegúrate de tener instalado *Python 3.x*.
2. Clona este repositorio o descarga el archivo .py.
3. Ejecuta el script en tu terminal:
   ```bash
   python nombre_de_tu_archivo.py
